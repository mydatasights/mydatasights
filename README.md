# MyDataSights

> A private, **offline-first**, portable knowledge workspace.

Drop any file — text, CSV, image, data. MyDataSights helps you explore it:
parses common formats, plots time-series, surfaces statistical patterns, and
(once you install a model) summarises, classifies, and embeds for
semantic search. See your data through any lens: document, chart, table,
timeline.

**No account. No cloud. After your chosen models are installed, no
internet is required at runtime.** First-run installation of an AI model
downloads the weights from Hugging Face Hub directly to your machine; after
that, everything happens locally. Outputs are pattern-based estimates and
should not be relied upon as authoritative ground truth.
